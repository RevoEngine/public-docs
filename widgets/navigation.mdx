## Open a detail view and return

Add this destination in **Widget destinations (JSON)**. Its Inline body is complete and reads the selected order ID from its input:

```json
{
  "orderDetail": {
    "sourceType": "INLINE",
    "codeType": "CODE_JS",
    "code": "return [[{ id: 'detail', type: 'TEXT', value: 'Order: ' + api.input().orderId }], [{ id: 'back', type: 'BUTTON', label: 'Back', on: { click: { type: 'BACK' } } }]];",
    "inputs": "{}",
    "readOnly": true,
    "timeout": 30,
    "memory": 128
  }
}
```

Use this source in the parent widget. Clicking a row replaces the current view while retaining its frame; Back restores the parent and its selected keys.

```js
return [
  [
    {
      id: 'orders',
      type: 'TABLE',
      rowKey: 'id',
      selection: { mode: 'multiple' },
      data: [{ id: 'order-1' }, { id: 'order-2' }],
      definition: [{ field: 'id', headerName: 'Order', type: 'TEXT' }],
      on: {
        rowClick: {
          type: 'OPEN_WIDGET',
          target: 'orderDetail',
          mode: 'replace',
          input: { orderId: { from: 'event', path: 'row.id' } },
        },
      },
    },
  ],
];
```

Use `mode: 'panel'` to open the destination beside its parent, or `mode: 'inline'` with an existing parent cell ID in `hostId` to mount it inside that cell. These modes start independent state: BACK navigates a retained replacement frame, not a parent in a different surface. Dismiss a panel with Escape or an outside click. For deeper drill-down, register another named destination and pass the next record ID explicitly.

Continue with [reactive widgets](/operate/reactive-widgets).

## Load a child on demand

An inline child needs a registered `widgetTargets` entry and a stable host ID. This parent source assumes the `customerDetails` destination has been registered. The destination reads `api.input().customerId`:

```js
const openChild = {
  type: 'OPEN_WIDGET', target: 'customerDetails', mode: 'inline', hostId: 'detailsHost',
  input: {customerId: {from: 'input', id: 'customer'}}
};
return [[{
  id: 'customer', type: 'INPUT', control: 'select', label: 'Customer',
  value: 'customer-1', searchable: true,
  options: [{label: 'Example customer', value: 'customer-1'}],
  on: {change: openChild}
}], [{
  id: 'loadDetails', type: 'BUTTON', label: 'Load details', on: {click: openChild}
}], [{id: 'detailsHost', type: 'EMPTY', height: 360}]];
```

The button loads only when selected; the input action loads after commit, including any configured debounce. Reopening the same source and inputs refreshes the child while retaining its draft. A change to source or inputs creates a new child scope. A child REFRESH affects its own IDs, leaving the parent's draft intact.

Hidden inline hosts do not mount or perform child reads. Showing a host again starts a fresh child read. Panels and inline children have independent loading/error, inputs and timers; nesting is limited to eight levels. Replacement navigation retains up to twelve frames, and its clickable breadcrumb restores a retained ancestor. Pending writes/probes must settle before back navigation.

Child target maps can inherit the registered maps of the parent. This is declarative navigation between authorized sources, not a way to load arbitrary browser components.
