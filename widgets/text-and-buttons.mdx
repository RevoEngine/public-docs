## Text

```js
return [
  [
    {
      id: 'summary',
      type: 'TEXT',
      value: '## Orders\n12 open orders need review.',
    },
  ],
];
```

Static TEXT renders its `value` as Markdown. A TEXT cell with `on.click` becomes an action button whose visible text is `label ?? value`; do not rely on rich Markdown in that clickable label.

## Buttons

This complete read-only widget refreshes its summary when the button is clicked:

```js
const targets = api.input()?.$widget?.targetIds ?? ['*'];
const rows = [];
if (targets.includes('*') || targets.includes('refreshSummary')) {
  rows.push([
    {
      id: 'refreshSummary',
      type: 'BUTTON',
      label: 'Refresh summary',
      on: { click: { type: 'REFRESH', target: 'summary' } },
    },
  ]);
}
if (targets.includes('*') || targets.includes('summary')) {
  rows.push([
    {
      id: 'summary',
      type: 'TEXT',
      value: 'Read at ' + new Date().toISOString(),
    },
  ]);
}
return rows;
```

`disabled: true` disables the button. `on.click` holds one action object. For a write, register an [EXECUTE target](/widgets/execute) with explicit permission and server-side input validation.

### Button appearance

BUTTON cells and TABLE toolbar buttons accept optional `appearance`:

| Field | Values | Meaning |
| --- | --- | --- |
| `variant` | `primary`, `secondary`, `ghost` | Native Revo theme; ghost has no resting fill or border. |
| `size` | `small`, `medium`, `large` | 32, 40 or 48 pixel button height. |
| `fullWidth` | boolean | Fill the containing cell when true. |

For a keypad key use `appearance: { variant: 'secondary', size: 'large', fullWidth: true }`; reserve primary for its main action. A cell's percentage width controls its layout area, while `fullWidth` controls the button inside that area. Omitted appearance preserves the existing defaults.

## Empty cells

```js
return [
  [
    { type: 'TEXT', value: 'Left', width: 45 },
    { id: 'detailHost', type: 'EMPTY', width: 10 },
    { type: 'TEXT', value: 'Right', width: 45 },
  ],
];
```

EMPTY deliberately reserves space within a row; use `width` to align siblings or leave an intentional gap. Add an ID when it should host an [inline destination](/widgets/navigation). It is not a loading or error indicator.

A spacer does not make the whole widget compact or set its maximum width. Extra EMPTY rows add height, and each spacer counts toward the row's cell limit. Use compact density to reduce gaps, blank surface to remove redundant inner padding, and maxWidth to bound a small utility. These [layout options](/widgets/source-configuration#layout) are independent and optional; full available width remains the default.

### Icons and accessible labels

BUTTON cells, section `buttons`, TABLE toolbar buttons and shared header actions accept `icon`, `ariaLabel` and `tooltip`. Use an existing application icon. Supply a non-empty `ariaLabel` when no visible label is present. A tooltip adds context; it does not replace the accessible name.

```js
return [[{
  id: 'refreshSummary', type: 'BUTTON', icon: 'fa-regular fa-arrow-rotate-right',
  ariaLabel: 'Refresh summary', tooltip: 'Refresh',
  appearance: {variant: 'ghost', size: 'small'},
  on: {click: {type: 'REFRESH', target: 'summary'}}
}], [{id: 'summary', type: 'TEXT', value: 'Summary content'}]];
```

A cell can expose a section toolbar through `buttons`; its actions use that cell as the source. For lightweight summaries, code, HTML and independently controlled copy/fullscreen, see [content readers](/widgets/content-readers).
