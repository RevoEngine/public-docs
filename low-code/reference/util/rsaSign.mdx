## `util.rsaSign()`

Signs data with RSA-PSS and SHA-256 asynchronously. PEM import and input conversion can still occupy the event loop.

### Signature

```ts
static rsaSign(
      privateKey: string,
      payload: string,
      passphrase?: string,
    ): Promise<string>;
```
### Example

```ts
const signature = await util.rsaSign(privateKey, 'hello', passphrase);
```
