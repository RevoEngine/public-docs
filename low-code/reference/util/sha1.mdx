## `util.sha1()`

Synchronous SHA-1 hash. Payload: at most 5242880 UTF-8 bytes (5 MiB).

Invalid types/options throw TypeError; size/range throws RangeError.

### Signature

```ts
static sha1(payload: string): string;
```
### Example

```ts
const digest = util.sha1('payload');
```
