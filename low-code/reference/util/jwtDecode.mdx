## `util.jwtDecode()`

Decodes a JWT without verifying it.

### Signature

```ts
static jwtDecode(
      token: string,
      options?: { complete?: boolean; json?: boolean },
    ): any;
```
### Example

```ts
const payload = util.jwtDecode(token);
```
