## `util.rsaDecrypt()`

Decrypts with RSA-OAEP and SHA-256 asynchronously. PEM import (including passphrase processing) still executes synchronously.

### Signature

```ts
static rsaDecrypt(
      privateKey: string,
      payload: string,
      passphrase?: string,
    ): Promise<string>;
```
### Example

```ts
const plain = await util.rsaDecrypt(privateKey, encrypted, passphrase);
```
