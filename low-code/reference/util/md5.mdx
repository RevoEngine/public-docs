## `util.md5()`

Synchronous MD5 hash. Payload: at most 5242880 UTF-8 bytes (5 MiB).

Invalid types/options throw TypeError; size/range throws RangeError.

### Signature

```ts
static md5(payload: string): string;
```
### Example

```ts
const digest = util.md5('payload');
```
