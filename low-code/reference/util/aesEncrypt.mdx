## `util.aesEncrypt()`

AES encrypt helper.

Payload: at most 1048576 UTF-16 code units; passphrase: at most 4096.

### Signature

```ts
static aesEncrypt(payload: string, passphrase: string): Promise<string>;
```
### Example

```ts
const encrypted = await util.aesEncrypt('secret', passphrase);
```
