## `util.sha256()`

Synchronous SHA-256 hash. Payload: at most 5242880 UTF-8 bytes (5 MiB).

Invalid types/options throw TypeError; size/range throws RangeError.

### Signature

```ts
static sha256(payload: string): string;
```
