## `util.sha256Async()`

Asynchronous SHA-256 hex digest of up to 32 MiB. Optional UTF-8 prefix and suffix are limited to 4096 bytes each.

### Signature

```ts
static sha256Async(payload: Uint8Array | string, prefix?: string, suffix?: string): Promise<string>;
```
