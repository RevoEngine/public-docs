## `util.generateHash()`

Generates a password hash.

Password: at most 4096 UTF-16 code units.

### Signature

```ts
static generateHash(
      password: string | undefined,
      rounds?: number,
    ): Promise<string>;
```
### Example

```ts
const hash = await util.generateHash(password, 10);
```
