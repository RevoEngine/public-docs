## `util.rsaVerify()`

Verifies an RSA-PSS SHA-256 signature asynchronously, preserving automatic salt-length detection.

### Signature

```ts
static rsaVerify(
      publicKey: string,
      payload: string,
      signature: string,
    ): Promise<boolean>;
```
### Example

```ts
const ok = await util.rsaVerify(publicKey, 'hello', signature);
```
