## `api.getOrSetInstanceCache()`

Reads a cache key or stores the fallback value atomically if it is missing.

### Signature

```ts
static getOrSetInstanceCache(
      key: string,
      value: any,
      seconds?: number,
    ): Promise<any>;
```
### Example

```ts
const state = await api.getOrSetInstanceCache('sync:state', { step: 'queued' }, 300);
```
