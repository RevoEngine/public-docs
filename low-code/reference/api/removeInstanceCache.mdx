## `api.removeInstanceCache()`

Removes cache keys.

Notes:
- Unavailable with `readOnly: true` (throws an error).

### Signature

```ts
static removeInstanceCache(key: string, wildcard?: boolean): Promise<void>;
```
### Example

```ts
await api.removeInstanceCache('sync:*', true);
```
