## `api.persistInstanceCache()`

Makes a cache key persistent.

Notes:
- Unavailable with `readOnly: true` (throws an error).

### Signature

```ts
static persistInstanceCache(key: string): Promise<void>;
```
### Example

```ts
await api.persistInstanceCache('sync:state');
```
