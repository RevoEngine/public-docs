## `api.expireInstanceCache()`

Sets cache TTL in seconds.

Notes:
- Unavailable with `readOnly: true` (throws an error).

### Signature

```ts
static expireInstanceCache(key: string, ttl: number): Promise<void>;
```
### Example

```ts
await api.expireInstanceCache('sync:state', 600);
```
