## `api.getInstanceData()`

Reads data from platform-managed sources.

### Signature

```ts
static getInstanceData(
      dataSource:
        | 'Users'
        | 'Groups'
        | 'RoleGroups'
        | 'Keys'
        | 'Secrets'
        | 'SecretsData'
        | 'Templates'
        | 'Events'
        | 'Schedule'
        | 'Jobs'
        | 'Webhooks'
        | 'Components'
        | 'Logs'
        | 'EventsHistory'
        | 'Endpoints'
        | 'Databases'
        | 'DatabaseData',
      request?: InstanceData,
    ): Promise<any>;
```
### Example

```ts
const jobs = await api.getInstanceData('Jobs', {
  take: 20,
  sort: ['-createdAt'],
});
```
