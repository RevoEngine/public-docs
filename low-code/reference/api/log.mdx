## `api.log()`

Adds a log entry.

Limits:
- INFO and DEBUG share a budget of 100 emitted entries in Endpoint executions,
  or 10,000 in Processor and Sandbox executions, including streaming Sandbox.
- WARN and ERROR each have a separate budget of 100 emitted entries.
- Error evidence remains in the execution result even after emission is
  limited: a bounded sample retains the first errors and the most recent one.
- Sampled-out messages are counted by level. A bounded aggregate appears when
  sampling starts, on further activity at most once per minute, and on final
  telemetry when counts changed. Other API methods do not consume this budget.
- Streaming Sandbox sends entries to its active SSE stream, which also has a
  backpressure queue limit.

### Signature

```ts
static log(
      log: string | LogInterface,
      type?: 'ERROR' | 'WARN' | 'INFO' | 'DEBUG',
      duration?: number,
      time?: string,
    ): void;
```
### Example

```ts
api.log(
  { message: 'Call finished', args: { status: 200 } },
  'INFO',
  120,
);
```
