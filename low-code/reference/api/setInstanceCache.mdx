## `api.setInstanceCache()`

Writes instance-scoped cache.

Notes:
- Unavailable with `readOnly: true` (throws an error).

### Signature

```ts
static setInstanceCache(
      key: string,
      value: any,
      seconds?: number,
    ): Promise<void>;
```
### Example

```ts
await api.setInstanceCache('sync:state', { step: 'loading' }, 300);
```
