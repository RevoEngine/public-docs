## `api.throw()`

Stores an HTTP-style response and aborts execution.

Notes:
- Reserved 502 and 503 codes are not allowed from Endpoint user code.

### Signature

```ts
static throw(code: number, body?: any): void;
```
### Example

```ts
api.throw(400, { message: 'customerId is required' });
```
