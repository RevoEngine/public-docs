## `api.deleteDatabase()`

Soft-deletes a logical database and its active partition subtree by name.

Notes:
- Unavailable with `readOnly: true` (throws an error).

### Signature

```ts
static deleteDatabase(name: string): Promise<void>;
```
### Example

```ts
await api.deleteDatabase('orders');
```
