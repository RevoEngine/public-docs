## `storage.restoreEntry()`

Restores an archived storage entry. Permanently deleted entries cannot be restored.

Notes:
- Unavailable with `readOnly: true` (throws an error).

### Overloads

```ts
static restoreEntry(
      storageEntryId: string,
      data: StorageRestoreInput,
    ): Promise<StorageEntryView>;

static restoreEntry(
      namespace: string,
      storageEntryId: string,
      data: StorageRestoreInput,
    ): Promise<StorageEntryView>;
```
### Example

```ts
const entry = await storage.restoreEntry(storageEntryId, { version: currentVersion });
```
