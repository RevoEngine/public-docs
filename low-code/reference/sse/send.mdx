## `sse.send()`

Send text as SSE data. Await for backpressure, not acknowledgement by the receiver.

### Signature

```ts
static send(data: string, options?: SseOptions): Promise<void>;
```
### Example

```ts
await sse.send('Hello', { event: 'delta', id: '1', retry: 3000 });
```
