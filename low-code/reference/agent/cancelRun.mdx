## `agent.cancelRun()`

Cancels a run, optionally recording a reason.

Notes:
- Unavailable with `readOnly: true` (throws an error).

### Signature

```ts
static cancelRun(
      agentRunId: string,
      data?: AgentRunCancelInput,
    ): Promise<AgentRun>;
```
### Example

```ts
const run = await agent.cancelRun(agentRunId, { reason: 'Operator stop' });
```
