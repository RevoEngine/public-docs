## `agent.getThread()`

Returns one assistant thread.

### Signature

```ts
static getThread(
      assistantThreadId: string,
      options?: { hideDeleted?: boolean },
    ): Promise<AssistantThread>;
```
### Example

```ts
const thread = await agent.getThread(assistantThreadId);
```
