## `agent.retryRun()`

Retries a failed or completed run from its retry policy.

Notes:
- Unavailable with `readOnly: true` (throws an error).

### Signature

```ts
static retryRun(agentRunId: string): Promise<AgentRun>;
```
### Example

```ts
const run = await agent.retryRun(agentRunId);
```
