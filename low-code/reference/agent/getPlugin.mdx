## `agent.getPlugin()`

Returns one agent plugin definition for an agent.

### Signature

```ts
static getPlugin(
      agentId: string,
      toolId: string,
    ): Promise<AgentPlugin>;
```
### Example

```ts
const tool = await agent.getPlugin(agentId, toolId);
```
