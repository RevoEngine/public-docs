## `agent.tickRun()`

Forces one autonomous tick for a run.

Notes:
- Unavailable with `readOnly: true` (throws an error).

### Signature

```ts
static tickRun(agentRunId: string): Promise<AgentRun>;
```
### Example

```ts
const run = await agent.tickRun(agentRunId);
```
