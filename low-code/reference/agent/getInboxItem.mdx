## `agent.getInboxItem()`

Returns one inbox item for an agent.

### Signature

```ts
static getInboxItem(
      agentId: string,
      agentInboxItemId: string,
    ): Promise<AgentInboxItem>;
```
### Example

```ts
const item = await agent.getInboxItem(agentId, agentInboxItemId);
```
