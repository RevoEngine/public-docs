## `agent.resumeRun()`

Resumes a paused run.

Notes:
- Unavailable with `readOnly: true` (throws an error).

### Signature

```ts
static resumeRun(agentRunId: string): Promise<AgentRun>;
```
### Example

```ts
const run = await agent.resumeRun(agentRunId);
```
