## `agent.restoreThread()`

Restores a deleted thread.

Notes:
- Unavailable with `readOnly: true` (throws an error).

### Signature

```ts
static restoreThread(assistantThreadId: string): Promise<void>;
```
### Example

```ts
await agent.restoreThread(assistantThreadId);
```
