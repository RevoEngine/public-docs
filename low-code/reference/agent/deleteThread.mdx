## `agent.deleteThread()`

Soft-deletes a thread.

Notes:
- Unavailable with `readOnly: true` (throws an error).

### Signature

```ts
static deleteThread(assistantThreadId: string): Promise<void>;
```
### Example

```ts
await agent.deleteThread(assistantThreadId);
```
