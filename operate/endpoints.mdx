The guard receives `body`, `query`, `parameters` and sanitized `headers`. A validation error stops the request before the target Component runs and before an SSE stream opens. Choose an inline guard for one route or a [JSON Validator](/low-code/json-validator) for a shared contract.

## Publish a route

1. In **Endpoints**, create an inactive definition. Set the method and path, then choose the Component and its version binding.
2. In **Options**, choose the guard, timeout and response contract. For a new JSON Endpoint, select the visible result element by name.
3. Activate and call the route using the [Endpoint runtime URL](/developers/endpoint-runtime). Test a valid request and one that fails the guard.

The [configuration reference](/operate/endpoint-configuration) covers route rules, access identity, version binding, validation errors, and a complete order command definition. For a first working route, use the [quickstart](/quickstart).

## Choose HTTP or SSE

| The caller needs | Use | What the caller sees |
| --- | --- | --- |
| One completed result | [HTTP responses](/operate/endpoint-http) | A status and optional response body. |
| Progress during the request | [SSE streams](/operate/endpoint-sse) | Live events and a terminal outcome. A configured disconnect policy governs the execution when the client leaves. |
| Work that can outlive the connection | [A durable Job](/operate/jobs) | An HTTP Endpoint can return `202` and a Job identifier. Check Job History for completion. |

## Operate the route

- Use a caller with [Endpoint invocation access](/developers/authentication). The [execution policy](/operate/endpoint-configuration#execution-policy) separately governs resource access inside the Component.
- Review the generated [runtime OpenAPI contract](/developers/endpoint-runtime) after changing the request or response. Check latest versus pinned bindings before activating a Component update.
- Follow the [Operation ID](/operate/traces#start-with-the-right-identifier) to diagnose a request. Endpoint invocations have no automatic retry. Use a [business idempotency key](/patterns/idempotency) for retryable writes.
- An inactive Endpoint still reserves its method and path. Deletion releases them. Restoring the original by ID returns `409 Conflict` if another Endpoint now owns that route.
