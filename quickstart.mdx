Send `POST /hello` with a name, receive a greeting, then locate its execution. An invalid request should stop at the guard.

## Before you start

Use a non-production instance. You need permission to create and activate a Component and Endpoint, and a credential allowed to invoke the Endpoint. Set `REVO_API_KEY` in your shell without pasting its value into the guide or your code.

<Steps>
  <Step title="Create the Response element">
    In **Components**, create a JavaScript Component named **Hello greeting** with a visible element named **Response**. Paste this complete element body.

    ```js Response
    const { name } = api.input('body');
    return { message: `Hello, ${name}!`, executionId: api.getExecutionId() };
    ```

    In the debugger, supply the same input envelope the Endpoint will build.

    ```json Sandbox inputs
    { "body": { "name": "RevoEngine" } }
    ```

    Expect the `Response` element to return a greeting and an execution ID. Save and activate the Component.
  </Step>

  <Step title="Configure POST /hello">
    In **Endpoints**, create a definition named **Hello greeting**, select the Component and set the method to **POST** and the path to **/hello**. Choose **HTTP**, **Success status** to **200** and **Result element → Response**. Set **Validation status** to **422**.

    Paste this schema into the inline request guard. It requires a nonempty name in the JSON body.

    ```json Inline guard
    {
      "profile": "strict",
      "schema": {
        "type": "object",
        "additionalProperties": "allow",
        "objectSchema": [
          {
            "property": "body",
            "schema": {
              "type": "object",
              "required": true,
              "objectSchema": [
                {
                  "property": "name",
                  "schema": { "type": "string", "required": true, "min": 1 }
                }
              ]
            }
          }
        ]
      }
    }
    ```

    Check the selected Component version and caller policy, then activate the Endpoint.
  </Step>

  <Step title="Send one valid request">
    Set `REVO_ENDPOINT_URL` to the Endpoint runtime base URL shown for your instance, without the trailing slash or `/hello`.

    ```bash Request
    curl --include --request POST "$REVO_ENDPOINT_URL/hello" \
      --header "Authorization: Bearer $REVO_API_KEY" \
      --header "Content-Type: application/json" \
      --data '{"name":"RevoEngine"}'
    ```

    The selected result is returned directly with HTTP **200**.

    ```json Response
    { "message": "Hello, RevoEngine!", "executionId": "<execution-id>" }
    ```
  </Step>
</Steps>

## Verify the result

Find the execution in [Observability](/operate/traces) using the response's execution ID. Send the same request with `--data '{}'` to see HTTP **422**. The guard rejects that request before the Component runs.

| What you see | Check first |
| --- | --- |
| `401` or `403` | Credential, invocation permission and Endpoint policy. |
| `404` | Active method, path and instance runtime URL. |
| An extra `Response` wrapper | Set **Result element** to **Response**. |
